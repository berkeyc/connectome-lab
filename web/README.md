# Connectome Lab · web

The website: species library, species explorer and the in-browser experiment lab.

```bash
npm install
npm run dev            # http://localhost:3000
npm run build          # production build (all pages are prerendered)
npm run check:presets  # run every preset on real and control brains in Node
```

Data comes from `public/data/`, generated by `python pipeline/build_web_bundle.py` in the repository root.
The simulation engine lives in `src/lib/engine/` and runs in a Web Worker (`sim.worker.ts`).
